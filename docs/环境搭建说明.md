# 环境搭建说明

## 一、运行打包版（推荐，最快体验）

**前置条件**：
- Windows 7/10/11（64 位）
- **无需安装 Python**（sidecar 已打包为独立 exe）
- 连接真实仪器需安装 IVI/Keysight/NI 任一 VISA 运行库（可选）

**步骤**：
1. 解压/拷贝 `dist` 目录到任意位置
2. 配置 DeepSeek API Key（二选一）：
   - **环境变量方式**（推荐，安全）：
     ```bat
     setx DEEPSEEK_API_KEY "sk-你的密钥"
     ```
     设置后需重开命令行/重启应用。
   - **配置文件方式**：编辑 `dist\agent\config.json`，把 `deepseek_api_key` 填为你的密钥：
     ```json
     {
       "deepseek_api_key": "sk-你的密钥",
       "model": "deepseek-v4-pro",
       "base_url": "https://api.deepseek.com"
     }
     ```
3. 双击 `dist\run.bat` 启动
4. 启动后顶栏状态显示 **「● Agent 在线（deepseek-v4-pro）」** 即为成功

> 若显示「Agent 未配置 API Key」，说明密钥未生效。

## 二、从源码编译（开发者）

### 2.1 依赖工具链

| 工具 | 版本要求 | 说明 |
|---|---|---|
| Qt | 5.12.2（**mingw73_64** 套件） | 安装时务必勾选 MinGW 7.3.0 64-bit |
| Python | 3.8+ | 开发 sidecar 与打包（PyInstaller）需要；运行时不需要 |
| PyInstaller | 6.x | 可选：`pip install pyinstaller`，用于打包 sidecar exe |
| MinGW | 7.3.0（Qt 自带） | 位于 `Qt\Tools\mingw730_64` |

> Qt 安装路径默认 `C:\Qt\Qt5.12.2`。若装在其他位置，请修改 `scripts\*.bat` 中的 `QT_BIN` / `MINGW_BIN` / `QT_INC` / `QT_LIB` 四个变量。

### 2.2 编译

双击运行（或在命令行执行）：
```bat
scripts\build.bat
```
编译产物：`build\release\ScopeAgent.exe`。

### 2.3 开发运行

```bat
scripts\run.bat
```

### 2.4 打包分发

```bat
scripts\package.bat
```
产物：`dist\` 目录（含 exe、Qt DLL、平台插件、sidecar、启动脚本）。拷贝整个 `dist` 目录即可分发。

## 三、DeepSeek 模型说明

| 模型 | 说明 |
|---|---|
| `deepseek-v4-pro` | 默认，推理能力强，适合复杂配置推理 |
| `deepseek-flash` | 更快更省，简单指令可选 |

修改模型：编辑 `agent/config.json` 的 `model` 字段，或设环境变量 `DEEPSEEK_MODEL`。

> **离线降级**：无密钥/断网时应用不会崩溃，Agent 显示未就绪，右侧「手动设置」面板仍可正常操作示波器。

## 四、常见问题（FAQ）

| 现象 | 原因 | 解决 |
|---|---|---|
| 提示「未找到 Python 且无 sidecar 可执行文件」 | dist 缺少 sidecar exe 且无 Python | 重新 package.bat；或安装 Python |
| 提示「Agent 未配置 API Key」 | 密钥未设置 | 按第一节配置密钥 |
| 提示「无法连接 DeepSeek」 | 网络不通 / 密钥无效 | 检查网络与密钥 |
| 双击 exe 报缺 DLL | 未用 run.bat 或 dist 不完整 | 用 dist\run.bat 启动；或重新 package.bat |
| 波形不变化 | 手动改动未点发送，或 Agent 未就绪 | 自然语言需先「发送给 Agent」 |
| SCPI 连接提示「未找到 VISA 库」 | 未安装 VISA 运行库 | 安装 Keysight/IVI/NI VISA |
