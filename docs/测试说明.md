# 测试说明

## 一、自动化测试（一键）

```bat
scripts\test.bat
```

共 6 个阶段，按序执行，任一失败即中止：

| 阶段 | 内容 | 是否需要网络 | 预期结果 |
|---|---|---|---|
| 1/6 | Python schema 单元测试（钳制/继承/白名单/软告警） | 否 | `ALL SCHEMA TESTS PASSED` |
| 2/6 | MCP 协议测试（initialize/tools-list/tools-call/stdio） | 否 | `ALL MCP TESTS PASSED` |
| 3/6 | C++ 驱动单元测试（波形合成/触发相位/方波取值/钳制/JSON 往返） | 否 | `ALL DRIVER TESTS PASSED` |
| 4/6 | C++ SCPI/VISA 驱动测试（VISA 加载/无效地址优雅失败/命令生成） | 否 | `ALL SCPI TESTS PASSED` |
| 5/6 | 离屏渲染测试（验证背景/网格/轨迹/触发线像素） | 否 | `RENDER_OK` |
| 6/6 | C++ Agent 集成测试（AgentClient→DeepSeek→驱动应用闭环） | **是** | `RESULT_OK` |

> 阶段 6 需要设置 `DEEPSEEK_API_KEY` 环境变量；未设置时自动跳过（打印 `[SKIP]`）。

### 阶段 6 说明
`tests/test_agent.cpp` 会构造一个 `AgentClient`，真实地：
1. 启动 Python sidecar 子进程
2. 健康检查直到就绪
3. 发送自然语言「显示一个 2kHz、2V 峰峰值的方波，时基调到能看到大约两个周期」
4. 校验返回配置并应用到 `VirtualScopeDriver`
5. 打印最终配置与 rationale

预期：频率=2000Hz、波形=square、时基≈100µs/div（10 格显示 2 个周期）、峰峰值=2Vpp。不同模型调用间垂直档位可能略有差异（0.5V/div 或 1V/div 均属合理）。

## 二、手工验收测试清单

启动应用后，按以下用例逐项验证：

| # | 操作 | 预期 |
|---|---|---|
| 1 | 启动后观察顶栏 | 显示「● Agent 在线（deepseek-v4-pro）」 |
| 2 | 观察波形区 | 暗色网格 + 青绿轨迹 + 橙色触发虚线 + 刻度标签，约 30FPS 流畅 |
| 3 | 输入「显示 1kHz 正弦波，3Vpp」点发送 | 波形变正弦，读数：频率 1kHz、峰峰值 3Vpp，日志显示 rationale |
| 4 | 输入「改成 100kHz 方波，触发电平 0.5V」 | 波形变方波，触发线移到 0.5V，触发读数更新 |
| 5 | 输入「显示三角波」 | 波形变三角波 |
| 6 | 输入「加一点噪声」 | 波形出现轻微毛刺 |
| 7 | 手动拖动「频率」旋钮 | 读数与波形实时变化（不依赖 Agent） |
| 8 | 切换驱动为「SCPI 示波器 (VISA)」 | 波形区显示「未连接」，可输入 VISA 地址点「连接仪器」；无硬件时日志提示连接失败 |
| 9 | 断网/清空密钥后启动 | 顶栏提示未配置，手动设置仍可用 |

## 三、边界与安全测试

以下用例验证「LLM 输出不可信」的双层钳制防护：

| # | 输入（恶意/越界意图） | 预期 |
|---|---|---|
| 1 | 「设置频率为 99999999 Hz」 | 频率被钳制到 10 MHz，读数显示 10 MHz |
| 2 | 「设置负的幅值」 | 幅值被钳制到下限 0.01 Vpp |
| 3 | 「设置时基为 0」 | 时基被钳制到 500 ns/div |
| 4 | 「设置一个不存在的波形」 | 波形回退 sine，日志含告警 |

> 验证点：无论 LLM 如何「幻觉」，实际下发的参数**永远**在合法范围内。
