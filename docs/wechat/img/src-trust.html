原则与推论

核心原则
Agent 只建议，宿主才是唯一真相源（single source of truth）
推论一
LLM 不进实时采集线程，只在配置路径与解释路径上活动
推论二
模型可换、协议可换，契约不可随意变——它是系统的地基
推论三
无 key / 断网时手动操作照常工作，这是正常状态而非错误

为什么是「双层」而不是一层

  • 两套代码在不同语言、不同进程实现
  • 任一层被绕过或自身有 bug，另一层仍能兜住
  • Agent 进程可独立升级、替换甚至多实例并存，宿主安全边界不变

钳制要「响」而不是静默

  • 静默改成合法值 → 用户只会认为「仪器失灵了」
  • 必须产出用户可见的告警并展示配置理由
  • 让人复核的是理由与告警，而非逐个核对参数
